# ADR-0036. «Сотрудники»: просмотр штата

Статус: **принято**. Дата: 20.10.2026. Требования: ERP-053 (часть: просмотр), M17. Правка сотрудников, PIN, табель,
сдельная и ведомость ждут D-13 и D-06.

## Контекст

Данные сотрудников перенесены (ADR-0033). Страница legacy «Сотрудники» смешивает два источника:
- **данные компании:** штат, оклады, условия труда, история условий;
- **данные из кода страницы:**
  - демонстрационный список сотрудников с PIN-кодами (`payrollStaff`);
  - демонстрационный список сдельщиков (`wageEmployees`);
  - сгенерированный табель;
  - ставки налогов.

Из второго источника считаются «ФОТ», «Нагрузка», «Начислено», выработка, явки и PIN.

## Решения

1. **`/hr`** (`HrController`, `Hr.vue`) показывает 1:1 с legacy (эталон `c54cf25`):
   - KPI «Всего», «Производственных», «АУП»;
   - «Штатное расписание»: подразделения и должности из кода legacy, занятые ставки — по точному названию должности
     сотрудника;
   - «Сотрудники»: карточки и таблица, поиск, фильтр подразделения;
   - карточку сотрудника и «📋 История изменений» (условия труда, новые сверху).
2. **Как в legacy:**
   - пустой тип сотрудника считается производственным;
   - кнопка «📊 Зарплатная ведомость» в шапке открывает вкладку ведомости, а отмечает третью вкладку.
   - **Права и вкладки:**
     - «🔐 PIN» в таблице и поле PIN в карточке видят директор и HR;
     - вкладку «Пользователи» видят директор и HR;
     - «Комиссии салонов» видят директор, главный бухгалтер и начальник салонов;
     - начальнику салонов показаны только «Сотрудники» и «Комиссии».
3. **Не показываются цифры из кода страницы:** «ФОТ», «Нагрузка», явки, PIN, выработка и «Начислено» сдельщиков (ADR-0002
   п. 93–95). В сверке legacy получает пустые демонстрационные списки.
4. **Начальник салонов:** отбор сотрудников салонов (по комментарию «Армада»/«Назарбаева» или должности) делает сервер.
   Legacy загружал весь штат в браузер (п. 98).
5. **Не сделано:**
   - запись: «Сохранить», «Уволить», «+ Сотрудник», штатное расписание;
   - вкладки «Сдельная выработка», «Зарплатная ведомость», «Табель», «Тарифы», «Комиссии салонов», «Пользователи».

   Эти кнопки и вкладки отвечают сообщением (п. 97).

## Проверено (20.10.2026)

- Визуальная сверка с `c54cf25`, оба режима оформления: всего 146 снимков, самое большое отличие 0,26 %. Снимки
  «Сотрудников»:

  | Экран | Отличие |
  |---|---|
  | Штатное расписание | 0,09–0,10 % |
  | Карточки | 0,21–0,22 % |
  | Таблица | 0,08–0,09 % |
  | Карточка сотрудника | 0,03–0,04 % |
- Текст штатного расписания и таблицы сотрудников совпадает с legacy.
- Фильтры (AC-08): 7 случаев, совпадает.
- Тесты `HrPageTest`, реестр — непросмотренных 0.
