# ADR-0027. Визуальная сверка на всех размерах экрана

Статус: **принято**. Дата: 16.10.2026. Требования: TEST-AC-04 (обе темы, 1440×900 и 1920×1080), TEST-AC-05 (900/899 px и
390×844), часть ERP-071; размеры — спецификация harness §5.

## Решения

1. **Что сравнивается.** `tests/visual/legacy_compare.py` снимает:
   - принятый эталон legacy (`8d275a1`) из `.local-audit/blobs` при заблокированной сети (кроме шрифтов);
   - новую версию с теми же строками: legacy получает ровно те данные, что показала новая версия.

   На каждом размере 130 снимков, обе темы: 16 перенесённых страниц, их вкладки и окна. Отличие — доля пикселей с
   разницей канала больше 24. Допуск 0,5 %.
2. **Размеры.**
   - `make visual-compare` — 1440×900, другой размер через `VIEWPORT=1920x1080`.
   - `make test-visual` (`scripts/visual-matrix.sh`) — все размеры спецификации, около 40 минут. Ненулевой код, если
     хоть один снимок выше допуска или размер не дал результата. Журнал ошибки сохраняется в `.local-audit/visual/`.
3. **Одинаковые условия съёмки.** Legacy управляется вызовами функций, новая версия — кликами Playwright. Клик
   прокручивает кнопку или вкладку в видимую область (на узком окне — вбок) и оставляет курсор над кнопкой (цвет
   наведения). Поэтому:
   - перед каждым снимком с обеих сторон сбрасывается прокрутка по обеим осям, вне окон;
   - на новой версии курсор уводится за пределы окна;
   - всплывающая карточка лида, которая ставится по своей кнопке, открывается без прокрутки на обеих сторонах;
   - журнал продаж на обеих сторонах намеренно прокручен к итогам.

   До этих правок на 390×844 расходились 46 снимков, на 900 px — 2. Сами страницы совпадали, различалась только
   прокрутка.

## Результат (16.10.2026, копия реальных данных)

`make test-visual`: все 650 снимков (5 размеров × 130) в пределах допуска. 390×844 — повторный прогон после того, как
снимок стал ждать окончания перехода цвета наведения (0,15 с); до этого один снимок тёмной темы давал 1,4 %.

| Размер | Снимков | Наибольшее отличие | Выше 0,5 % |
|---|---:|---:|---:|
| 1440×900 | 130 | 0,26 % | 0 |
| 1920×1080 | 130 | 0,16 % | 0 |
| 900×900 | 130 | 0,41 % | 0 |
| 899×900 | 130 | 0,49 % | 0 |
| 390×844 | 130 | 0,33 % | 0 |

**Найдено.** На 390×844 сверка показала незаписанное отличие. В карточке лида «⋯» legacy выводит код источника
(`call`), а новая версия — название («Звонок»), как и сам legacy в списке лидов. Отличие записано: ADR-0002, п. 86.

## Не сделано

- Неперенесённые страницы и их окна — по мере переноса.
- Состояния «пусто», «загрузка», «ошибка» (AC-07) — отдельно. Ошибки и обрывы связи проверяет `make reliability-check`
  (ADR-0025), большие реестры — `LargeRegistriesTest`.
- В CI сверка не запускается: нужен Playwright на раннере — отдельное решение о зависимостях.
