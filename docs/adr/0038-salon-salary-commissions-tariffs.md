# ADR-0038. Зарплата продавцов, комиссии салонов, тарифы: просмотр

Статус: **принято**. Дата: 22.10.2026. Требования: ERP-059 (часть), ERP-053 (часть), ERP-055 (часть); изменение условий
оплаты ждёт D-06 и D-13.

## Контекст

Сотрудники с окладами, процентами комиссии и историей окладов перенесены (ADR-0033). Три экрана legacy только
показывают эти данные или считают из них без ставок и налогов, поэтому их можно перенести до решений о зарплате.

## Решения

1. **«Отчёт салонов» → «Расчёт зарплаты продавца»** — 1:1 с legacy `renderSalonReport`:
   - для каждого продавца из заказов месяца берётся карточка сотрудника с тем же именем;
   - комиссия = база × процент, округлённая; база — продажи или оплаты (метод из карточки, по умолчанию «% от
     продаж»);
   - итого = оклад + комиссия; при двух и более продавцах — строка «Итого»;
   - продавец без карточки считается с нулём, как в legacy.

   Сервер отдаёт условия оплаты только продавцов из заказов салона, которые видит учётная запись. Legacy загружал в
   браузер весь штат (ADR-0002 п. 81).
2. **«Сотрудники» → «Комиссии салонов»** — legacy `renderSalonCommissionsSettings` и `showSalaryHistory`:
   - начальник салонов, менеджеры Армады, Назарбаевой и общие, с окладом, процентом и методом;
   - отбор как в legacy: салон в комментарии, без уборки;
   - «📅 История» — история окладов, новые сверху.

   Значения показываются так, как legacy показывает их тем, кто не может менять: «Только просмотр.». Изменение оклада и
   процента пишет историю окладов — с правилами зарплаты (п. 101).

   Вкладку видят директор, главный бухгалтер и начальники салонов (legacy `canSeeCommissions`). С 23.10 только им сервер
   и отдаёт процент, метод и историю окладов; legacy загружал их всем, кто открывает «Сотрудников» (п. 111).
3. **«Сотрудники» → «Тарифы»** — список 24 операций со ставками из кода legacy (`tariffData`), как его рисует
   `renderTariffs`. Правки legacy не сохранял; здесь правка, добавление и удаление отвечают сообщением (п. 102).

## Проверено (22.10.2026)

- Визуальная сверка с `c54cf25`, оба режима оформления: всего 154 снимка, самое большое отличие 0,26 %. Новые экраны:
  - отчёт салонов — 0,06 %;
  - «Комиссии салонов» — 0,07 и 0,08 %;
  - «Тарифы» — 0,06 и 0,07 %.
- Текст «Расчёта зарплаты продавца», «Комиссий салонов» и «Тарифов» совпадает с legacy. Фильтры отчёта салонов — 15
  случаев, совпадает.
- Тесты `SalonReportTest`: условия оплаты отдаются только для продавцов видимых заказов. `HrPageTest`: процент, метод
  и история окладов. Реестр — непросмотренных 0.
