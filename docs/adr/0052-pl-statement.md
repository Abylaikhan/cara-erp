# ADR-0052. «Финансы» → «📊 P&L»: отчёт о прибылях и убытках (часть 1)

Статус: **принято**. Дата: 23.10.2026. Ответ бухгалтера 23.10, № 36: формулы отчётов — как есть; P&L считается по
реализации. Требования: ERP-060 (часть), M11.PL.

## Контекст

Вкладка legacy «📊 P&L» (`buildPL`/`renderPL`) показывает строку KPI, отчёт «Отчёт о прибылях и убытках» с источником
каждой строки, шесть подотчётов (помесячно, выручка по направлениям и категориям, расходы по статьям, дерево выручки, оценка
себестоимости) и «Постоянные затраты / мес». Legacy считает всё в браузере по загруженным таблицам; у многих строк есть
запасные варианты, которые берут примерные списки из программы страницы.

## Решения

1. **Считает сервер** (`PlReport`) за период страницы — точными суммами, по перенесённым данным. Страница запрашивает отчёт
   при открытии вкладки и при смене периода. Legacy складывал дробные числа в браузере; на экране — целые тенге, как в legacy.
2. **Строки — как в legacy:**
   - **выручка** — реализация периода;
   - **прямые материалы** — строки входящих ЭСФ «Товары» периода, кроме категорий материалов, которые legacy относит к ОПР
     (инструмент, расходники, прочее), плюс статьи «Производственные», названные материалами (бук, лес, стекло, краска…);
   - **зарплата сдельная** — колонка «Сдельная» зарплатной ведомости периода;
   - **ОПР** — статьи «Производственные», названные расходами (станок, полировка, ремонт…); остальные — «не учтены никуда»,
     как в legacy;
   - **оклады АУП** — Оклад, Премия, Отпускные, Займ, Больничный ведомости, без ведомости — выплаты зарплаты периода;
   - **коммерческие, аренда и прочее** — расходы периода по верхней статье («Коммерческие», «Хозяйственные»), платёж
     поставщику — по статье его карточки, плюс строки авансовых отчётов; платёж за ЭСФ «Товары» не задваивается.
3. **Запасные варианты legacy на примерных данных не используются** (ADR-0002 п. 126):
   - прямые материалы по складу и техкартам — списаний и техкарт нет (D-12), значит 0;
   - сдельная по «выработке» и нормам изделий, оклады и налоги по примерным спискам, постоянные затраты из программы — 0;
   - «Налоги на сдельщиков» — 0: налоги программа не считает (№ 50).
4. **Подотчёты** — следующими частями. Их карточки на месте; в теле и в «📥 Excel» — сообщение.
5. **Права** — страница «Финансы» (директор, главный бухгалтер), как в legacy.

## Проверено (23.10.2026)

- `PlReportTest`: каждая строка отчёта на синтетических данных — ЭСФ (материал, инструмент, услуга, другой месяц),
  статьи «Производственные», поставщик по статье карточки, «Коммерческие», «Хозяйственные», ведомость по видам начислений и
  без деталей, авансовый отчёт; без ведомости — выплаты зарплаты; отчёт приходит только по запросу и за свой период.
- На копии данных отчёт за год считается за 0,35 с. Сверка с legacy — в ближайшей сверке раз в три дня (26.10).
