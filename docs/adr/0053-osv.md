# ADR-0053. «Финансы» → «📋 ОСВ»: управленческая оборотно-сальдовая ведомость

Статус: **принято**. Дата: 24.10.2026. Ответ бухгалтера 23.10, № 36: формулы отчётов — как есть. Требования: ERP-061,
M11.OSV.

## Контекст

Вкладка legacy «📋 ОСВ» (`buildOSV`/`renderOSV`/`ddOSVAccount`) строит проводки по плану счетов РК из денег, реализации,
себестоимости P&L, авансовых отчётов и ЭСФ. Показывает сальдо на начало, обороты и сальдо на конец по счетам, проверку
«Дебет = Кредит» и проводки счёта по клику.

## Решения

1. **Считает сервер** (`OsvReport`) за период страницы, точными суммами, теми же проводками, что legacy:
   - деньги: оплата покупателя Дт 50/51 Кт 62, поставщику Дт 60, зарплата Дт 70, налог Дт 68, аванс Дт 71 (возврат —
     обратно), займы и прочий приход Кт 91.1, дивиденды Дт 84; переводы между своими счетами проводок не дают; прочий расход
     Дт 91.2, приход Кт 91.1;
   - реализация Дт 62 Кт 90.1; себестоимость продаж из P&L (материалы + сдельная) Дт 90.2 Кт 43 последним днём периода;
   - строки «Прочий расход» авансовых отчётов Дт 91.2 Кт 71; ЭСФ «Товары» Дт 10 Кт 60, остальные — Дт 7210 Кт 60;
   - разница колонок — на 84 «Нераспределённая прибыль», итоги — после неё.
2. **Как в legacy, включая его особенности** (№ 36):
   - начальное сальдо кассы и счёта складывается из проводок до периода **и ещё раз** из суммы операций до периода;
   - проводки на примерных данных — списания по складским документам, ФОТ примерного штата, выпуск по техкартам — не
     создаются, их данных нет (ADR-0002 п. 126).
3. **«Всё время»** — все операции без начального сальдо (legacy брал 2026 год), как в «ДДС». Выгрузка без периода, как в
   legacy, подписана 2026-01-01 — 2026-12-31.
4. **Детализация счёта** — проводки периода, где счёт в дебете или кредите: дата, документ, содержание, корреспонденция,
   суммы; сервер отдаёт их по клику.
5. **Права** — страница «Финансы».

## Проверено (24.10.2026)

- `OsvReportTest`: проводки по видам операций; перевод без проводки; операция после периода не входит; двойное начальное
  сальдо кассы, как в legacy; 84 закрывает разницу; итоги после 84; порядок счетов; проводки счёта по запросу.
- **Сверка с legacy** — `make pl-compare` (PL_YEAR=2025, 2026): все строки ОСВ (15), итоги и число проводок (7517 за 2026,
  1180 за 2025) совпадают.
