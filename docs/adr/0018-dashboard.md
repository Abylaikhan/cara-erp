# ADR-0018. Дашборд (M01, ERP-064)

Статус: **принято**. Дата: 15.10.2026. Источник legacy (`c917d37`): разметка `page-dashboard` L2226–2296;
`showPage('dashboard')` L16555; `setDashPeriod`, `renderDashboard` L24546–24770.

## Решения

1. **Суммы считает сервер** (`DashboardController`) по перенесённым данным, по месяцам, в `numeric`. Это выручка реализаций,
   оплаты поставщикам, выплаты ЗП, приход и расход, расходы по категориям, остатки склада, долг поставщикам. Страница
   складывает месяцы выбранного периода. Все периоды дашборда — целые календарные месяцы, поэтому месячных сумм достаточно.
2. **Периоды** «Месяц», «Квартал», «Год» и выбранный месяц считаются по бизнес-поясу Asia/Almaty. Legacy сдвигал границы на
   день через UTC: «Месяц» в октябре показывал «2026-09-30 — 2026-10-30», а расходы по категориям — за сентябрь
   (ADR-0002, п. 64).
3. **«Заказов в работе»** — заказы в статусе «В работе». Legacy считал статусы `production` и `ready`, которых у заказов нет,
   и всегда показывал 0 (ADR-0002, п. 65).
4. **Суммы в тенге.** На долларовом счёте сумма операции в долларах, тенге — в `amount_fx`; на тенговом `amount_fx` — доллары
   для справки (как в legacy `fmtTxAmt`). Legacy в графике прихода/расхода брал `amount_fx` на тенговом счёте (доллары), а в
   оплатах поставщикам — доллары на долларовом счёте. Здесь везде тенге (ADR-0002, п. 66).
5. **Расходы по категориям** названы так, как их называет раздел «Деньги» (`txCatLabel`: значок и название, неизвестный код —
   как есть). Legacy выводил коды (`supplier`, `salary`…). Выдача аванса заменена строками авансовых отчётов, как в legacy
   (ADR-0002, п. 67).
6. **Начисления ЗП** (`salary_accruals`, M20) не перенесены. «ФОТ (месяц)» показывает «—» и «с переносом начислений ЗП», в
   графике ФОТ столбцы «Начислено» пустые, «Расход денег» — по операциям (ADR-0002, п. 68). После ERP-057 появятся данные.
7. Права: страница — по шаблону ролей (`dashboard`). Заказы выбираются через `ChannelScope`; ни у одной роли с дашбордом нет
   канала.

## Проверка

`tests/Feature/Dashboard/DashboardTest.php`: суммы по месяцам до тиына, доллары и тенге, переводы, авансы, критичные остатки,
долг, доступ. Сверка с данными legacy (снимок `20261014T214659Z`, логика legacy с исправлениями п. 2–5): выручка 13 месяцев,
оплаты поставщикам 14, выплаты ЗП 26, приход 73, расход 33, расходы 335 пар «месяц × категория», склад 6299 позиций,
критичных 0, долг поставщикам, заказы — совпадает. `make visual-compare`: 0,08–0,09 % (отличие — карточка «ФОТ»).
