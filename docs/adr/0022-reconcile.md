# ADR-0022. Сверка с офисом (M16), часть 1: просмотр (ERP-052)

Статус: **принято**. Дата: 16.10.2026. Источник legacy (`8d275a1`): `page-reconcile` L7138–7199; `setReconcilePeriod`,
`getReconcileDateFilter`, `renderReconcile` L15728–15962; `showPage('reconcile')` L16794.

## Решения

1. **Как в legacy:**
   - заказы канала учётной записи за выбранный период (все, месяц, свои даты; по дате заказа);
   - отправленные заказы и основной долг: оплаты — приходы с номером заказа канала, считаются по всем заказам канала;
   - заказы в очереди и в работе и долг по предоплате 50 %;
   - переводы в офис: для кассы салона — расходы кассы «в офис», иначе возвраты подотчётных сумм на имя учётной записи;
   - KPI для дилера (6) и салона (6).
2. **Данные.** Legacy загружал в браузер дилера все денежные операции компании (`loadMoneyFromDB`). Здесь сервер отдаёт только
   суммы оплат по заказам канала и переводы самой учётной записи (ADR-0002, п. 79).
3. Офисные роли (директор, главный бухгалтер) канала не имеют: legacy показывает им пустую сверку, здесь так же.
4. «Месяц» — календарный месяц бизнес-пояса; суммы в тенге.

## Проверка

`tests/Feature/Money/ReconcileTest.php`. Сверка оплат с копией legacy для всех пяти дилеров — совпадает. `make visual-compare`
под дилером — 0,03–0,04 %, весь текст страницы (181 строка) совпадает.
