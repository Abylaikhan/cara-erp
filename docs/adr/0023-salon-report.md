# ADR-0023. Отчёт салонов (M21), часть 1: текущий период (ERP-059)

Статус: **принято**. Дата: 16.10.2026. Источник legacy (`8d275a1`): `page-salon_report` L8118–8244; `initSalonReport`,
`renderSalonReport`, `showSalonReportTab` L16283–16610.

## Решения

1. **«Текущий период» — как в legacy:**
   - заказы салонов, которые видит учётная запись (`ChannelScope`; выбор салона скрыт у учётной записи одного салона), за
     месяц по дате создания; заказы без даты показываются всегда;
   - KPI, таблица продавцов, все заказы с клиентом (конечный клиент; «—», если там только название салона).
   - Месяц заканчивается своим последним днём. Legacy считал конец через UTC и в Алматы терял последний день.
   - Статус «В работе» показывается словами; legacy выводил код `progress` (ADR-0002, п. 81).
2. **Ждут «Сотрудников»** (ERP-053, ERP-059, D-13):
   - «Расчёт зарплаты продавца» — оклад, процент и метод комиссии хранятся в «Сотрудниках»;
   - вкладки «Платёжная ведомость» и «История ЗП» — `salon_payroll` и сотрудники.
   На их месте — сообщение.

## Проверка

`tests/Feature/Money/SalonReportTest.php`; `make visual-compare` под начальником салонов — 0,06 %; KPI, продавцы и заказы
совпадают с legacy текстом.
