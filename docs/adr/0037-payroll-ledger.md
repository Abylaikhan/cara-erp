# ADR-0037. «Зарплатная ведомость»: просмотр

Статус: **принято**. Дата: 21.10.2026. Требования: ERP-057 (часть: просмотр), M19. Начисление и выплаты ждут D-06.

## Контекст

Ведомость legacy ничего не рассчитывает по ставкам. Она складывает записи зарплаты: начисления (`salary`) и выплаты
(`payment`), которые перенесены (ADR-0033). Поэтому её можно перенести до решений о расчёте зарплаты.

## Решения

1. **`/payroll`** (`PayrollController`, `Payroll.vue`) — 1:1 с legacy (`c54cf25`) по `renderSalaryLedger` и `renderPayouts`.
   - **Ведомость по сотрудникам** за месяц или произвольный период:
     - остаток на начало (все начисления «к выдаче» минус все выплаты до начала периода);
     - начисления по видам из `details`;
     - удержания;
     - «К выдаче»;
     - «Выдано» за период;
     - остаток на конец;
     - сотрудники без начислений в периоде, но с ненулевым остатком.
   - **Месяцы** — от последнего месяца с записями (или текущего) до ноября 2025. Выбран последний месяц с записями.
   - **Свернуть столбцы** начислений и удержаний.
   - **Итоги, KPI**, «Остаток на начало → на конец».
   - **«💵 Журнал выдач»** — по датам и итогом по сотрудникам, с поиском. «Выдано» в строке открывает журнал по этому
     сотруднику.
   - **Меню строки:**
     - «👤 Карточка сотрудника» открывает карточку в «Сотрудниках» (`/hr?emp=`);
     - «📋 Операции за период» открывает «Начисления ЗП» с поиском по имени (`/accruals?search=`).
2. **Как в legacy:** «Все / Производство / Салоны» не фильтрует ведомость — legacy не применяет этот выбор.
3. **Исправлено (ADR-0002 п. 99):**
   - legacy при открытии показывал пустую таблицу — ведомость рисовалась только после смены фильтра;
   - поиск legacy не фильтровал ведомость.
4. **Не сделано (п. 100):** начисление из меню строки (D-06), выгрузки в Excel (ERP-067). Расчётная ведомость вкладки
   «Сотрудники» (по ставкам и налогам в коде legacy) — D-06.

## Проверено (21.10.2026)

- **Визуальная сверка с `c54cf25`**, оба режима оформления: всего 150 снимков, самое большое отличие 0,26 %. Снимки
  ведомости — 0,12 %, журнал выдач — 0,06 %.
- **Текст совпадает с legacy:** KPI, строки и итоги ведомости последнего месяца с записями, журнал выдач.
- **Фильтры и сортировки (AC-08):** 18 случаев, совпадает.
- **Пустая база (`make visual-empty`):** ведомость и журнал выдач совпадают; всего 128 снимков, самое большое отличие
  0,47 % (прежний экран склада).
- **Сценарии в браузере (`make e2e`):** пройдены, dev-база не изменилась.
- **Остальное:** `make check` — 288 тестов, реестр — непросмотренных 0. Ответ `/payroll` — 72 мс, 1,6 МБ (4439 записей).
