# ADR-0020. Новый принятый эталон legacy: `8d275a1`

Статус: **принято**. Дата: 16.10.2026. Основание: решение заказчика 16.10.2026 — перенос по актуальной версии `index.html`
(ERP-001). Предыдущий эталон — `c917d37` (ADR-0016).

## Что изменилось в legacy

Коммиты `4e6948f`, `2643bf5`, `cafce46`, `8d275a1` от 15.10.2026; строки `index.html` +176 / −1; функций +11, изменённых 0.

- **«Деньги» → «Касса»:** кнопка «🧩 Объединить платежи» (`cmOpen`, `cmBuildGroups`, `cmApply`, `cmLinkOne`,
  `cmRestoreFile` и др.).
  - Расходы кассы с одной датой и номером документа в описании (или с одинаковым описанием) сводятся в одну операцию.
    Старые операции удаляются, а выплаты зарплатной ведомости (`salary_accruals`) перепривязываются к новой или создаются.
  - Группы с привязками к заказам, ЭСФ и авансам и группы с разными категориями не трогаются.
  - Перед изменением браузер скачивает файл-копию; по нему можно восстановить состав.
- **Дашборд:** у графика ФОТ подсказка в легенде заменена пояснением под графиком: что входит в «Начислено» и
  «Расход денег».

## Решение

1. Принятый эталон — `8d275a1` (`tools/harness/config.json` → `source.accepted_ref`); `make visual-compare` сверяет с ним.
2. Копия данных legacy обновлена только чтением: снимок `20261015T172631Z` — 44 таблицы, 243 GET-запроса, других методов 0.
   Все перенесённые разделы загружены заново, сверка — 0 расхождений.
   - **Деньги.** В legacy объединили платежи кассы: из копии исчезла 581 операция, появилось 8 сводных.
     - `legacy:import money` теперь удаляет операции, оплаты заказов и авансовые отчёты, которых больше нет в legacy.
       Значения удалённых строк сохраняются в журнале аудита (`legacy.removed`).
     - Ссылки обновляются до удаления: оплата заказа должна указывать на существующую операцию (проверяется), авансовый
       отчёт теряет ссылку, которую потерял и legacy.
     - Повторный импорт ничего не меняет.
   - Заказы: +22, изменено 10. Реализации: +30.
3. Перенесено: пояснение под графиком ФОТ на дашборде; кнопка «🧩 Объединить платежи» в кассе — с сообщением. Объединение
   меняет денежные операции и выплаты зарплатной ведомости, поэтому ждёт проведения денег и начислений ЗП (ERP-031…033,
   ERP-057, D-03, D-11; ADR-0002, п. 77).
4. Визуальная сверка: legacy хранит одну позицию прокрутки для всех страниц. Его дашборд стал длиннее, и следующие страницы
   открывались прокрученными. Сверка теперь возвращает прокрутку legacy наверх перед каждым снимком, кроме намеренно
   прокрученных.

## Проверка

кавычкой — ADR-0002, п. 75).
