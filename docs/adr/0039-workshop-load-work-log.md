# ADR-0039. «Загрузка цехов» и «Журнал работ»: просмотр

Статус: **принято**. Дата: 22.10.2026. Требования: ERP-044 (часть). Проведение этапов — ERP-042 (D-05, D-06), доска
цехов — ERP-044 после D-12.

## Контекст

Этапы, записанные в рабочем листе производства, перенесены вместе с прогрессом позиций (ADR-0014): по каждой позиции —
этап, цех, отметка «проведено» с датой и исполнители с КТУ. Две вкладки «Производства» legacy только читают эти данные:
«Загрузка цехов» (`renderWorkshopLoad`) и «Журнал работ» (`collectWorkLogEntries`, `renderWorkLog`). Поэтому их можно
перенести до решений о проведении этапов и сдельной оплате.

## Решения

1. **Данные.** Позиции с записанными этапами и список сотрудников (фильтр «Все исполнители», как `employeesData` в legacy)
   приходят при первом открытии одной из двух вкладок (`work`). Позиция — по номеру заказа и номеру строки, как ключ
   `номер|индекс` legacy.
2. **«Загрузка цехов»** — 1:1 с legacy:
   - позиции, у которых есть непроведённые этапы, по цехам;
   - срочность по дате позиции: просрочено, ближайшие 7 дней, в срок, без даты.

   «Сегодня» — дата в поясе Asia/Almaty. Legacy брал дату через UTC, и в Алматы до 05:00 она была вчерашней
   (ADR-0002 п. 104).
3. **«Журнал работ»** — 1:1 с legacy:
   - строка на каждый проведённый этап и каждого исполнителя (без исполнителей — «—»), за выбранный месяц;
   - фильтры: цех, исполнитель, заказ, категория, товар, работа.

   Отличия от legacy:
   - список месяцев — двенадцать месяцев. В legacy там один пункт «${m}»: текст шаблона, который не выполняется, поэтому
     виден только текущий месяц (ADR-0002 п. 103);
   - сумму этапа (`computeStageAmountFor`) legacy здесь считает, но не показывает. Здесь её тоже нет; суммы этапов
     показывает «Сдельная оплата» (ADR-0042);
   - «📥 Excel» отвечает сообщением — выгрузки ERP-067.
4. **Не перенесено:**
   - доска цехов: техкарты и журнал этапов legacy не сохраняет (D-12);
   - рабочий лист производства: правка и проведение — ERP-041/042.

## Проверено (23.10.2026)

- Визуальная сверка с `c54cf25`, оба режима оформления: «Загрузка цехов» — 0,00 %, «Журнал работ» — 0,22 % и 0,25 %.
- Текст «Загрузки цехов» (цеха и позиции) и «Журнала работ» совпадает с legacy.
- Фильтры «Журнала работ» — 43 случая, совпадает; записанное отличие — список месяцев (п. 103).
- Тест `ProductionJournalTest`: этапы приходят с вкладкой, позиция без этапов не попадает, исполнители и даты.
