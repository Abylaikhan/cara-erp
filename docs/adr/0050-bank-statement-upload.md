# ADR-0050. «Сверка с банком»: загрузка выписки из Excel

Статус: **принято**. Дата: 23.10.2026. ADR-0044, п. 5 (PhpSpreadsheet, вариант «А» вопроса № 65). Требования: ERP-034
(часть), M12.BANKRECON_IMPORT. Продолжение ADR-0015, часть 5.

## Контекст

Во вкладке legacy «Сверка с банком» кнопка «📥 Загрузить выписку» читает выписку Kaspi или Halyk в браузере (SheetJS) и
записывает её строки в `bank_statement_raw` счёта этого банка. Строки сравниваются с журналом по дням. В журнал денег они
попадают только по «Перенести» — это проведение денег, оно ждёт D-03 и D-11.

## Решения

1. **Файл читает сервер** (PhpSpreadsheet), как legacy (`handleBankReconImport`):
   - первый лист, текст ячеек в том виде, в каком его показывает Excel;
   - строка заголовков — первая из первых 50, где заполнено не меньше пяти ячеек и есть колонка Kaspi («Наименование
     бенефициара…») или Halyk («Контрагент» и «БИН контрагента»);
   - счёт — тот, который legacy берёт для этого банка.
2. **Строки — по правилам legacy:**
   - пустые строки, строка с номерами колонок и строки без дебета и кредита пропускаются;
   - дебет — расход, кредит — приход;
   - у Kaspi название и БИН берутся из ячейки «бенефициар / отправитель»;
   - даты «ДД.ММ.ГГГГ» с временем или без; несуществующая дата — без даты.
3. **Суммы точные.** Разделитель дробной части — последняя запятая или точка, пробелы и «₸» убираются, как в legacy.
   Число записывается десятичным, без двоичной дроби. Строка с суммой меньше нуля отклоняет файл с номером строки.
4. **Повтор не добавляет строк.** Строка, которая уже есть в сверке счёта, пропускается — по номеру документа, без номера —
   по дате, виду, сумме и контрагенту, как в legacy. Повторы внутри файла тоже. Сообщения — как в legacy: «Готово!
   Добавлено новых операций: N (пропущено как уже загруженные: M)», «Все N операций из файла уже есть в сверке — новых не
   найдено.», «Не удалось найти строку заголовков…», «Не найдено операций для загрузки.».
5. **Одна транзакция.** Файл загружается целиком или не загружается. Legacy при ошибке части строк загружал остальные.
   Файл — `.xlsx` или `.xls`, до 10 МБ и до 20 000 строк.
6. **Права и журнал.** Загружать может тот, кому открыта страница «Деньги», как в legacy. Проверяет сервер. Загрузка — в
   журнале аудита: банк, сколько строк прочитано и добавлено.
7. **Повторный перенос сверки из legacy** удаляет строки, которых нет в legacy. Поэтому, как только выписку загрузили
   здесь, перенос `bank_statements` останавливается с объяснением и ничего не меняет.

## Проверено (23.10.2026)

- `BankStatementUploadTest`:
  - выписка Kaspi: строка номеров колонок, пустая строка и «Итого» пропущены; суммы «97 300,40» и «52183.17»;
    название и БИН из ячейки бенефициара; повторная загрузка — «новых не найдено»;
  - выписка Halyk — на свой счёт; «1.234,5» → 1 234,50; несуществующая дата — без даты;
  - файл без заголовков, не Excel и роль без страницы отклоняются;
  - числа, даты и названия — как в legacy.
