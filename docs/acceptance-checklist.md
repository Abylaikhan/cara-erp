# Приёмка перенесённых разделов — чек-лист для заказчика

Обновлено: 24.10.2026. Кто принимает разделы — вопрос № 26 (`docs/open-questions.md`).

**Как пользоваться.** Откройте раздел в новой системе и рядом — в старой, на одних и тех же данных. Пройдите пункты
«Проверьте»: если совпадает — отметьте ✅, если нет — напишите номер пункта и что видите. «Отличия» — сделанные нами и
записанные изменения против старой системы (номера пунктов `docs/adr/0002-ui-deviations.md`); их проверять как отличие,
а не как ошибку. «Ждёт решения» — что в разделе ещё не сделано и почему.

Во всех разделах: данные — копия старой системы (только чтение, старая база не менялась); каждое действие проверяет
сервер, а не скрытая кнопка; одновременная правка одной записи двумя людьми не теряет изменений — второму сообщается.

---

## 0. Вход, меню, общее

**Проверьте**
- [ ] Вход по логину и паролю; неверный пароль — сообщение; выход.
- [ ] Меню показывает разделы своей роли; чужой раздел по ссылке не открывается.
- [ ] Светлая и тёмная тема; вид страниц совпадает со старой системой.

**Сверено:** снимки экрана всех перенесённых страниц в двух темах — отличие не больше 0,5 % пикселей (`make visual-compare`).

**Отличия:** п. 1–10 (нет подсказок с паролями, нет отладочной панели, шрифты свои, неперенесённые разделы показывают
пояснение), п. 57 (блокировка PIN), п. 83–84, 89 (большие списки, ошибка сервера, окна загрузки).

**Ждёт решения:** пользователи, пароли, роли, PIN (D-13, № 39–44); новая версия старой системы `d7d448f` (№ 82).

## 1. Дашборд

- [ ] Период «Месяц / Квартал / Год», KPI: выручка, заказы, склад, ФОТ, поставщики, долг.
- [ ] Графики: выручка, ФОТ и «Начислено», приход/расход, расходы по категориям.

**Сверено:** цифры — совпадают со старой системой; снимки 0,08 % и меньше. **Отличия:** п. 64–68.

## 2. Производство (просмотр)

- [ ] Журнал позиций: статус по реализации и рабочему листу, номер позиции в заказе, фильтры.
- [ ] Очередь, рабочий лист, загрузка цехов, журнал работ; выгрузки в Excel.

**Сверено:** прогресс 1095 позиций перенесён без расхождений; снимки 0,02–0,06 %. **Отличия:** п. 52, 53, 103, 104, 107.
**Ждёт решения:** проведение этапов, техкарты, доска цехов (D-05, D-06, D-12).

## 3. Склад

- [ ] «По складам», «По категориям», «Цехи»; «Все остатки» с фильтрами и итогами; алиасы.
- [ ] «+ Материал» в два шага.
- [ ] Приходная накладная: черновик не меняет остаток, проведение прибавляет один раз и пишет движение.

**Сверено:** 6299 материалов и алиасы — без расхождений; снимки 0,00–0,02 %; приход — `make e2e`.
**Отличия:** п. 21–27, 123. **Ждёт решения:** перемещение, списание, инвентаризация, отмена движения (D-04, D-05, № 47).

## 4. Закупки

- [ ] Заявки (таблица и канбан), фильтр, поиск, KPI, ручная заявка; план-факт.

**Сверено:** снимки 0,00–0,01 %. **Отличия:** п. 40, 41.

## 5. Входящие ЭСФ

- [ ] Список с фильтрами и KPI, смена типа, окно ЭСФ со строками.
- [ ] Импорт XML (несколько счетов, ошибки), «📥 Товары в Excel».
- [ ] Сверка с оплатами: связи платежа и группы, частичная оплата — не больше остатка ЭСФ и платежа.
- [ ] «📦 Принять»: строка принимается на склад один раз приходной накладной.

**Сверено:** 1386 ЭСФ, 3471 строка, 1506 связей — без расхождений; снимки 0,06–0,26 %; частичная оплата и приём — `make e2e`.
**Отличия:** п. 28–30, 112, 119, 124. **Ждёт решения:** автоподбор связей (№ 53).

## 6. Поставщики

- [ ] Список, KPI, поиск, фильтры; карточка со статьёй расходов; вкладки «По категориям», «Рейтинг».
- [ ] Импорт CSV, объединение дублей, импорт из ЭСФ.

**Сверено:** 265 поставщиков — без расхождений; те же группы дублей, что в старой системе; снимки 0,02–0,11 %. **Отличия:** п. 20.

## 7. Каталог

**Сверено:** 1652 товара — без расхождений; снимки 0,07–0,09 %. **Отличия:** п. 11, 12.

## 8. Покупатели

- [ ] «Контрагенты»: оборот, число заказов, окно лица (ИИН/БИН из 12 цифр).
- [ ] «Дилеры»: правка ячеек, «+ Строка», импорт CSV и шаблон.
- [ ] «Сверки»: акт с контрагентом, дилером, салоном за период; выгрузка и печать.

**Сверено:** 5226 записей — без расхождений; акт с дилером совпадает текстом (210 строк); снимки 0,00–0,10 %.
**Отличия:** п. 13–19, 80. **Ждёт решения:** заказы дилера — по каналу или по названию (№ 75); салоны и продавцы (D-13).

## 9. Продажи

- [ ] «Все заказы»: фильтры, сортировка, итоги; «✓ Завершить» заказ дилера.
- [ ] Журнал реализации, отчёт по заказам, рабочий лист реализации.

**Сверено:** 3124 заказа, 4152 позиции, 1338 реализаций — без расхождений; снимки 0,00–0,29 %.
**Отличия:** п. 42–50, 56, 91, 105, 106. **Ждёт решения:** создание и правка заказов (D-02, D-12, № 33); отгрузки и
проведение реализации, реставрации (D-08).

## 10. CRM

- [ ] Воронка, задачи (баннер просрочки), клиенты салонов, доски заказов, проекты.
- [ ] Салон видит только свои лиды; дилер и начальник цеха — только «Проекты».

**Сверено:** 4964 лида и задачи — без расхождений; снимки 0,00–0,30 %; `make e2e`.
**Отличия:** п. 31–39, 51, 58–63, 86. **Ждёт решения:** конверсия (№ 79).

## 11. Финансы

- [ ] Период страницы и выбор заказов; «📥 Excel» в шапке — отчёт P&L за период с дебиторкой.
- [ ] «📊 P&L»: KPI, отчёт с источниками строк, помесячно, выручка по направлениям и категориям, расходы по статьям, дерево
      выручки, оценка себестоимости — с выгрузками.
- [ ] «Дебиторка», «Закупки», «ДДС» с детализацией.
- [ ] «📈 Маржинальность» по категориям (оценка без техкарт), выгрузка.
- [ ] «Точка безубыточности»: план постоянных затрат месяца (сохраняется сам), факт, «✓ Проведено», структура, KPI, график.
- [ ] «📋 ОСВ»: проверка Дт = Кт, детализация счёта, выгрузка.

**Сверено:** `make pl-compare` — каждое число P&L, его таблиц, маржинальности и ОСВ в целых тенге, текст на экране строка
в строку и картинки (маржинальность, KPI и график ТБУ) — совпадает за 2025 и 2026; дебиторка, закупки, ДДС — совпадают,
снимки 0,02–0,08 %; ТБУ — `make e2e`.
**Отличия:** п. 69–73, 88, 117, 118, 126–128 (примерные данные старой системы не используются; ошибки старой системы,
которые не давали файла или показывали другой месяц, исправлены).
**Ждёт решения:** «Центры прибыли» (№ 80), «P&L по видам деятельности» (№ 81), маржа по позициям (D-12), приём оплаты в
дебиторке (D-03, № 35, № 38).
