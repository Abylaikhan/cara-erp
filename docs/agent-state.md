  выгружать может только тот, кому открыта страница. Перенесены 11 выгрузок; каждая совпадает с файлом legacy из тех же строк.
- Тесты на PostgreSQL: 314. Реестр: непросмотренных 0. Сверка с legacy: 168 снимков, наибольшее отличие 0,26 %.

## Ответы бухгалтера: счета, связи ЭСФ, приход на склад (23.10.2026, ADR-0047…0049)

- **Ответы бухгалтера 23.10** (29 вопросов) записаны в `docs/open-questions.md` и `docs/decisions-request.md`; статусы — в
  листе «Вопросы бухгалтеру». Уточнения ждут № 33, 35, 38, 47, 51, 53, 75; списки к № 70 и 72 — у заказчика на проверке.
- **«Сотрудники»** без вкладок «Сдельная выработка» и «Зарплатная ведомость» (№ 77).
- **«Деньги» → окно «Расчётный счёт»** сохраняет счёт и начальный остаток; касса учитывает свой остаток (№ 37, ADR-0047).
- **«Сверка с оплатами»** сохраняет и удаляет связи; частичная оплата не больше остатка ЭСФ и платежа (№ 52, 54,
  ADR-0048). Автоподбор — после № 53.
- **«Склад» → приходная накладная**: черновик, проведение с журналом движений (№ 45, 46, ADR-0049); приход из карточки
  ЭСФ — проведённой накладной, строка ЭСФ принимается один раз. Перемещение и списание ждут модели остатков цехов.
- **«Сотрудники» → «Штатное расписание»** — справочник: перенесён из программы legacy, правится с сохранением (№ 76, ADR-0051).
- **«Финансы» → «📊 P&L»**, часть 1: KPI, отчёт о прибылях и убытках, постоянные затраты — считает сервер за период (№ 36, ADR-0052). Подотчёты — следующими частями; сверку P&L с legacy добавить к сверке 26.10.
- **«Сверка с банком» → «📥 Загрузить выписку»**: Kaspi и Halyk из Excel читает сервер, повтор не добавляет строк (ADR-0050).

- Тесты на PostgreSQL: 339; `make e2e` — 17 новых проверок. Реестр: непросмотренных 0.
